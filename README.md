# Python Practice

A personal collection of small Python examples and notebooks for learning and
practising programming fundamentals. The materials currently include basic
variables and data types, with `app.py` as a minimal standalone script.

## Project contents

- `1-Pythob Basics/` — introductory examples and Jupyter notebooks.
- `app.py` — a small script that can be run with `python app.py`.

## Run an example

Run the standalone script from the repository root:

```bash
python app.py
```

To run the variables example:

```bash
python "1-Pythob Basics/variables.py"
```

For notebook support, install the listed dependency with
`python -m pip install -r requirements.txt`, then open a notebook in an
environment that supports Jupyter notebooks, such as VS Code.
